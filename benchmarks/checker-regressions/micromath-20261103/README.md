# Micromath replay inputs, 2026-11-03

These are MUS-reduced certificates generated by Primo `cf82b726`, with normal
preprocessing and experimental object-sort erasure. They are checker inputs,
not SMT-LIB scripts. No Primo build or original SMT benchmark is needed to
inspect them.

The archive contains the exact `input.primo`, `challenge.umd`, `problem.cnf`,
and `problem.lrat` for each case, plus expected diagnostics and SHA-256 metadata.
It includes no external source code, binaries, credentials, or SSH configuration.
Use a built Micromath checkout at `505588a6a0b184c992c3cbcd97721507365ec428`:

```sh
MICROMATH_DIR=/absolute/path/to/Micromath bash /path/to/unpacked/archive/replay.sh goel-weakening-mask
MICROMATH_DIR=/absolute/path/to/Micromath bash /path/to/unpacked/archive/replay.sh seq-extension-vars
```

Each command should pass conflict checking, then exit 1 in `prove-lrat` with the
recorded diagnostic. Exact replay consumes the saved LRAT and requires no
CaDiCaL installation. A failed replay can leave a partial `replayed.ump`.

## Goel: persistent weakening-mask failure

`goel-weakening-mask.primo` has 11,985 CNF clauses and 95 theory conflicts.
Its saved trace was generated using CaDiCaL
`7b99c07f0bcab5824a5a3ce62c7066554017f641` with `--no-factor`, in addition to
`prove-cnf`'s usual `-q -n --lrat --no-binary` arguments. It introduces no fresh
SAT variables and has no negative LRAT hints. Both Micromath `df5c5d3` and
`505588a` report `Logic failure: global literal weakening mask` on this same
trace. A separate `--plain` trace also fails on both versions. Jobs 345309 and
345317 record these comparisons. This is not established as a regression in
Mirek's latest optimization. The example is reproducible, not minimized for the
checker failure; only the theory-lemma set was minimized.

## SEQ: fresh variables in the generated SAT proof

`seq-extension-vars.primo` has 9,064 CNF clauses and 404 theory conflicts.
The saved default CaDiCaL trace introduces fresh variables. Micromath `505588a`
reports `Logic failure: literal outside snapshot variables`; general RAT and
extension replay are outside its documented RUP-only support. Regenerating LRAT
with `--no-factor` succeeds on this same certificate in both Micromath versions,
including independent kernel replay (job 345309). The Primo input is unchanged.

The checked-in `.primo` files are identical to the archive inputs. Large generated
challenge/LRAT files stay in the local reproduction archive; `manifest.json`
records their hashes. The source benchmark paths identify the public SMT-LIB
inputs used to generate the certificates; source-to-CNF conversion proof remains
future work.
